# Project
- Greenfield personal-assistant product concept and prototype workspace.
- Main deck: `index.html`, a self-contained 11-slide interactive Russian presentation.
- UI architecture studio: `ui-options.html`, six selectable home-screen models using one visual system and shared data.
- Visual style studio: `design-options.html`, the same daily-flow scenario rendered in four selectable themes.
- Both studios persist explicit choices locally in the browser.
- Local visuals and their generation prompt live under `assets/`.
- No production application architecture exists yet; the deck recommends the «Поток+» product direction.
