# Кизуна (pagent)

## Выкладка — через GitHub, не по ssh

- Релиз — это `git push origin main`. На каждый пуш в `main` `.github/workflows/deploy.yml` гоняет юнит-тесты (`npm test`) и, если они зелёные, сам запускает `./deploy.sh` с раннера GitHub (ключ — секрет `DEPLOY_SSH_KEY`). Прогоны встают в очередь, параллельно не летят.
- С рабочей машины `./deploy.sh` по ssh не запускать: он не нужен, а в авто-режиме Claude Code его блокирует проверка разрешений.
- «Релизь» и «сделай в приложении» = тесты → коммит своих изменений → `git push origin main` → проверить прогон: `gh run list --workflow deploy.yml`, `gh run view <id>`. Спрашивать «релизить?» не нужно.
- Упал прогон на мигающем юнит-тесте (полный `npm test` иногда валит случайный тест, поодиночке он зелёный) — перезапустить: `gh run rerun <id> --failed`.
- В этом дереве часто работают несколько сессий Claude сразу: перед коммитом смотреть `git status` и коммитить только свои изменения. Пушатся только коммиты, чужие незакоммиченные правки на прод не уедут.
